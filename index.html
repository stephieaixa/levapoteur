Problemes identifies

🔴 Statut "En pause" (On-hold) desactive

La feature on_hold_status est desactivee au niveau du compte. Le statut existe mais ne peut pas etre utilise par les agents.

Difference cle :
● Pending = on attend une reponse du client
● On-hold = on attend une action interne (fournisseur, logistique, SAV)
🟡 Processus SAV classe en Pending — a revoir

Les statuts "En attente (Retour SAV)" et "En attente de reception (SAV)" sont en categorie Pending, ce qui signifie que le compteur SLA tourne comme si on attendait le client.

Or quand le produit est chez nous pour test/diagnostic, le blocage est cote entreprise — le statut logique serait On-hold.

Impact concret : le SLA continue a tourner pendant le SAV, generant de fausses violations. Impossible de mesurer le temps reel d'attente client vs temps de traitement interne.
💡 Recommandation
  • Activer la feature On-hold dans Admin > Compte
  • Migrer les statuts SAV de Pending vers On-hold
  • Reconfigurer les triggers et macros SAV associes
  • Le SLA s'arretera automatiquement pendant le On-hold
